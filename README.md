# Ekantipur Scraper

A Playwright-based web scraper that extracts entertainment news and editorial cartoons from [ekantipur.com](https://ekantipur.com).

Built as part of the Audio Bee Web Scraping Intern technical assessment.

---

## What It Does

- Scrapes the **top 5 articles** from the Entertainment (मनोरञ्जन) section
- Scrapes the **most recent editorial cartoon** from the Cartoon section
- Saves all extracted data to `output.json`

## Setup

### 1. Install uv (if not already installed)

**macOS/Linux:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source $HOME/.local/bin/env
```

**Windows (PowerShell):**
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 2. Create project and install dependencies

```bash
mkdir ekantipur-scraper
cd ekantipur-scraper
uv init
uv add playwright
uv run playwright install chromium
```

### 3. Run the scraper

```bash
uv run python scraper.py
```

## Output Format

Data is saved to `output.json` with the following structure:

```json
{
  "entertainment_news": [
    {
      "title": "Article headline in Nepali",
      "image_url": "https://...",
      "category": "मनोरञ्जन",
      "author": "Author Name"
    }
  ],
  "cartoon_of_the_day": {
    "title": "Cartoon title",
    "image_url": "https://...",
    "author": "Cartoonist Name"
  }
}
```

## Technical Notes

- Uses **sync Playwright API** — simpler and sufficient for this task
- Images are lazy-loaded by the site — the scraper scrolls the page to trigger loading, then reads from the `src` attribute (not `data-src`) after the lazy loader swaps them
- Category name is scraped live from the page header (`div.category-name p a`), not hardcoded
- Cartoon author and title are parsed by splitting the description text on ` - ` (e.g. `"गजब छ बा! - अविन"`)
- All text saved with `ensure_ascii=False` to preserve Nepali (Devanagari) characters
- Error handling at three levels: navigation, selector waiting, and per-card extraction — so partial failures don't crash the whole script
